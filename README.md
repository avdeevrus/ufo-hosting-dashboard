# 🛰️ UFO Hosting · Dashboard окупаемости рекламы

Управленческий дашборд: расходы на Яндекс.Директ ↔ реальные оплаты клиентов, LTV, CAC, payback, retention. Одна страница, тёмная тема, без перегруза.

## Что внутри

Главный экран показывает за выбранный период:

- 8 ключевых KPI крупно (Расход / Доход / ROMI / Клиентов / CAC / ARPU / Средний чек / LTV-to-CAC)
- Помесячную динамику расхода, дохода и новых клиентов
- Структуру продаж по семействам продуктов
- Топ клиентов по LTV
- Gauge повторных оплат
- Когортный анализ дохода по месяцам регистрации

Дополнительно в свёрнутых секциях: помесячная таблица, разбивка по кампаниям Директа, локациям серверов, экспорт CSV.

## Деплой бесплатно: Streamlit Community Cloud

Это самый простой способ опубликовать дашборд по своему URL без покупки домена. Бесплатно, прямо из этого GitHub-репо.

**Шаги (3 минуты):**

1. Перейдите на [share.streamlit.io](https://share.streamlit.io) и войдите через GitHub (аккаунт `avdeevrus`)
2. Нажмите **«New app»**
3. Repository: `avdeevrus/ufo-hosting-dashboard`, Branch: `main`, Main file: `src/app.py`
4. Жмёте **Deploy** → через ~2 минуты получаете публичный URL вида `https://ufo-hosting-dashboard.streamlit.app`
5. (опционально) В настройках приложения **Settings → Sharing** можно ограничить доступ только по конкретным email-ам, если не хотите чтобы это было полностью публично

После деплоя любые `git push` в `main` автоматически обновляют опубликованный дашборд.

> ⚠️ **Данные клиентов в репо не попадают** — реальные `data/orders/*.csv` и `data/ads/*.xlsx` исключены через `.gitignore`. После деплоя клиент сам загружает свежую выгрузку через интерфейс (сайдбар → «📥 Загрузить выгрузки»). Файлы держатся в памяти сессии и не уходят на диск сервера.

## Запуск локально

```bash
./run.sh
```

Откроется на `http://localhost:8520`. При первом запуске поставит зависимости в `.venv/`.

## Подключение Яндекс.Директ API (для прямой синхронизации)

Сейчас расходы тянутся из XLSX-выгрузок. Чтобы статистика подтягивалась автоматически прямо из аккаунта Директа:

1. Зайдите на [oauth.yandex.ru](https://oauth.yandex.ru) → «Создать приложение»
2. Платформа: **Веб-сервисы**, права (scope): **`direct:api`**
3. После создания получите **OAuth-токен** для своей учётки (https://yandex.ru/dev/direct/doc/start/token.html)
4. Добавьте токен в Streamlit Cloud:
   - В дашборде на share.streamlit.io откройте Settings → **Secrets**
   - Добавьте `yandex_direct_token = "ваш_токен"`
5. Перезапустите приложение → в сайдбаре появится «🔗 Я.Директ подключён»

Дальше можно вызывать `yandex_direct.fetch_campaign_report(...)` из `src/yandex_direct.py` чтобы тянуть отчёты программно. (Поверх этого можно добавить кнопку «Sync» — скажите, когда подключите токен).

## Загрузка свежих данных клиентом

Клиент заходит на дашборд → в сайдбаре раздел **📥 Загрузить выгрузки**:

- **CSV** — выгрузки «Содержимое заказов» из админки UFO Hosting (несколько за разные периоды — дубликаты по `ID покупки` автоматически убираются)
- **XLSX** — отчёт по кампаниям Яндекс.Директ

Дашборд парсит, склеивает, дедуплицирует и показывает обновлённые цифры сразу. Период фильтра подстраивается под загруженные данные.

## Структура проекта

```
src/
├── app.py            ← Streamlit UI (одна страница, тёмная тема)
├── data_loader.py    ← парсеры CSV + XLSX (с диска и из upload)
├── metrics.py        ← KPI, когорты, payback, retention
└── yandex_direct.py  ← модуль для API Я.Директ (требует токен)
.streamlit/
└── config.toml       ← тёмная тема + размер upload
```

## Главное ограничение и его решение

В выгрузках заказов нет источника трафика per-client (Yandex Direct vs SEO vs прямой) — это исправляется со стороны GA4 (передача события `purchase` с `transaction_id` поштучно). После настройки появится точная атрибуция.

Сейчас сравнение делается агрегированно по месяцу, с настраиваемой долей платного трафика в сайдбаре.
